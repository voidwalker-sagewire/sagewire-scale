# SageWire Scale Service

Hardware-independent weighing infrastructure for the SageWire platform.

## Purpose

The Scale Service provides a consistent API for weight measurement regardless of the underlying hardware.

Responsibilities include:

- Scale registration
- Heartbeats
- Raw weight ingestion
- Weight normalization
- Stable weight detection
- Weight event history
- Session management

Applications should communicate with the Scale Service through the SageWire Gateway.
